# Python Pong Game

A classic two-player Pong game built with Python and the Turtle graphics module while learning Python programming.

## Features
- Two-player keyboard controls
- Ball and paddle movement
- Collision detection and bouncing
- Score tracking
- Ball speed changes after paddle collisions

## Concepts Practiced
- Object-oriented programming (OOP)
- Classes, objects, methods, and attributes
- Inheritance and Python modules
- Coordinates and movement
- Game loops, collision detection, and scoring

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run `python main.py`.
